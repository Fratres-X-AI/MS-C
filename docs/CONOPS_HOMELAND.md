# CONOPS — Homeland / Critical Sites — MS-C Mantle

**Document ID:** MS-C-CONOPS-H-001 · **Maturity:** Planning vignette · **Not authorized ops**

---

## 1. Mission

Reduce the probability that Group 1–2 UAS EO/IR detectors obtain stable
classification / lock on designated soft targets at fixed sites, as a
**persistent passive layer** under detect → deny → kinetic.

---

## 2. Site classes (v1 vignettes)

| Class | Example assets | Kit emphasis |
|-------|----------------|--------------|
| Substation | Transformer banks, buswork | Net / panel tiles over high-contrast metal |
| Tank pad | Vertical tanks, pumps | Wrap / skirt tiles + low-e accents |
| Pipeline corridor | Above-ground segments, valve skids | Linear net runs + joint covers |

---

## 3. Employment cycle

1. **Survey** — Photo/IR stills (partner) or synthetic planning scenes.  
2. **Design** — Run Mantle optimizer → kit manifest + tile sheets.  
3. **Install** — Site crew applies nets/coatings per BOM stub (planning).  
4. **Audit** — Periodic drone pass; C2 compares detector lock vs baseline.  
5. **Refresh** — Re-optimize / replace weathered tiles on schedule or after ASR rise.

No “arm” cue required. Mantle is always on once installed.

---

## 4. Escalation

If audit shows persistent lock:

1. Confirm coverage integrity (tears, wrong aspect).  
2. Employ **MS-V** / smoke for transient screen if threat is active.  
3. Cue **MPL-D** if dazzle effector present and ROE allows.  
4. Escalate to kinetic / LE per site policy — **not** automatic from Mantle.

---

## 5. Constraints / red lines

- Visual change must be acceptable to site owners / public.  
- No claim of FAA / LE authorization from this repo.  
- Materials tox / fire rating / grounding interactions = partner domain.  
- Export screening before any controlled tech data exchange.
