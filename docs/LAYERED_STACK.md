## Comparison

| Dimension | **MS-C Mantle** | **MS-V Veil** | **MPL-D** |
|-----------|-----------------|---------------|-----------|
| Mode | Passive materials / patterns | Active obscurant cloud | Active laser effector |
| Spectrum | VIS texture + LWIR emissivity stack | VIS + NIR + MWIR cloud | ~940 nm NIR dazzle |
| Persistence | Weeks+ (refresh cycle) | ~120 s dense | Pulse / duty cycle |
| Cue to arm | None | Throw decision | Track cue + arm authority |
| Safety case | Materials / fire / public visual | Fill tox / throw | LSO / NHZ / Protocol IV |
| Failure mode | Pattern ignored / weathered | Wind / burn / settle | Miss / eye hazard inhibit |

## Complementary employment

| Situation | Prefer |
|-----------|--------|
| Always-on site hardening | **Mantle** |
| Active FPV pass, need seconds of screen | **Veil** (+ visual smoke) |
| Cue-quality track, need sensor denial pulse | **MPL-D** |
| Soft layers fail | Kinetic / LE |

Never claim one product replaces the others.
